GEPARU ADMIN

Aplikasi Khusus Divisi Sosial dan Penanggalan Bencana (SDPB)

📖 Panduan Instalasi

GEPARU Admin digunakan untuk membantu pengelolaan administrasi Layanan Aduan Sosial.

1
Klik Download APK GEPARU Admin untuk mengunduh APK.
2
Setelah APK selesai diunduh, buka file APK tersebut dari perangkat Hp Android.
3
Jika Android meminta izin untuk memasang aplikasi dari sumber tersebut, izinkan pemasangan.
4
Setelah selesai dipasang, buka aplikasi GEPARU Admin.

🔄 Tentang Pembaruan

Jika tersedia versi aplikasi terbaru, link download pada halaman ini akan diperbarui sesuai versi APK terbaru.
