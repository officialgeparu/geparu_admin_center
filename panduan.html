GEPARU ADMIN

Aplikasi Khusus Divisi Sosial dan Penanggulangan Bencana (SDPB)

📱 Panduan Instalasi

GEPARU Admin digunakan untuk membantu pengelolaan administrasi Layanan Aduan Sosial.

1
Klik tombol Download APK GEPARU Admin di bawah ini.
2
Setelah APK selesai diunduh, buka file APK tersebut dari perangkat Android.
3
Jika Android meminta izin untuk memasang aplikasi dari sumber tersebut, izinkan pemasangan.
4
Setelah selesai dipasang, buka aplikasi GEPARU Admin.

🔄 Tentang Pembaruan

Aplikasi GEPARU Admin menggunakan sistem WebView.

Artinya, perubahan pada website GEPARU Admin yang dilakukan melalui GitHub dapat diperbarui tanpa harus membuat ulang aplikasi Android, selama perubahan tersebut berada pada website.

🌐 Alternatif Tanpa APK

Admin juga dapat membuka GEPARU Admin langsung melalui browser tanpa melakukan instalasi APK.
